O `srectl` sobe uma plataforma completa no **kind**: GitOps com Argo CD, a stack de
observabilidade LGTM, segurança (Kyverno, Trivy, Falco), serviços demo e drills de caos —
e transforma cada tema numa aula prática.

```bash
srectl up            # cluster + Argo CD + todos os apps, via GitOps
srectl status        # matriz de saúde
srectl demo load     # gera tráfego, acende os dashboards
```

Siga uma trilha abaixo, ou vá direto para os **Tutoriais**.
